# Attendance + Shiksha — 22 June Snapshot

Historical service-based Apps Script web app for program management, attendance, devotee biodata, Shiksha records, and owner/admin dashboards.

## Snapshot contents

- `Code.gs`, `Config.gs`, and `appsscript.json` — entry point, configuration, and runtime manifest
- `AuthService.gs`, `ProgramService.gs`, `AttendanceService.gs`, `DevoteeService.gs`, `AdminService.gs`, `Utils.gs` — application services
- `SetupScripts.gs` — sheet setup and optional demo-data helpers
- `App.html` — single-page interface
This is an archive, not a production deployment guide. Confirm the spreadsheet ID and schema in `Config.gs`; review setup/demo functions before running them, especially against live data.
