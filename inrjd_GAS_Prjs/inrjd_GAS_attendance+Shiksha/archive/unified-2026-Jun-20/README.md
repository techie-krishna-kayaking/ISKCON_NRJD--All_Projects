# Attendance + Shiksha — 20 June Snapshot

Historical unified Apps Script implementation for program setup, attendance, devotee biodata, Shiksha forms, and owner/admin dashboards.

## Snapshot contents

The `.gs` files split authentication, configuration, programs, attendance, devotees, Shiksha, dashboard, and utilities. The HTML files provide the program, attendance, Shiksha, and admin pages. `WebApp.gs` and `Workflow.gs` connect the flows.

This is an archived snapshot, not the current deployment source. Its sheet schema, permissions, and behavior may differ from later versions. Review all write/setup functions and compare the code with the live spreadsheet before running it.
